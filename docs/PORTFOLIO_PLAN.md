# 포트폴리오 보완 계획

AgentLab을 AI Native 엔지니어 채용용 포트폴리오로 쓰기 위해 보완할 항목과 진행 상황입니다.
목표는 "잘 만든 데모"에서 **"검증되고, 측정되고, 설명 가능한 운영 제품"**으로 끌어올리는 것입니다.

평가자가 저장소를 열었을 때 5분 안에 확인하는 것을 기준으로 우선순위를 정했습니다.

1. 첫 화면(README)에서 무엇을 왜 만들었는지, 실제로 동작하는지 보이는가
2. 코드가 검증되는가 (테스트, CI 배지)
3. AI 시스템을 측정했는가 (eval 수치)
4. 어려운 문제를 어떻게 풀었는지 설명돼 있는가 (아키텍처, 설계 결정)
5. 코드 구조와 마감 상태가 깔끔한가 (lint 0, 거대 파일 없음)
